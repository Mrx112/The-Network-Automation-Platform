02 — Arsitektur Sistem

Backend FastAPI + Frontend React, terhubung real-time

Arsitektur modern dengan pemisahan concern yang jelas antara API, UI, dan koneksi device.

Backend (FastAPI)

⚙

REST API dan WebSocket endpoints. Menangani device management, config generation, task execution, dan network discovery. Dibangun dengan Python 3.8+.

FastAPI WebSocket Netmiko AsyncIO

Frontend (React + TypeScript)

🎨

UI modern dengan Material Design. React Router untuk navigasi, TanStack Query untuk data fetching, dan React Hot Toast untuk notifikasi.

React TypeScript MUI Vite

Connection Manager

🔌

Manajemen koneksi device dengan connection pooling. Mendukung SSH, Telnet, NETCONF, RESTCONF, dan gNMI. Optimized timeouts dan reusable connections.

SSH Telnet NETCONF RESTCONF
03 — Fitur Utama

Semua yang dibutuhkan untuk otomatisasi jaringan

📦
Device Management

Kelola perangkat jaringan dengan add, edit, delete. Monitor status online/offline dan test koneksi dengan latency measurement.

🔍
Network Discovery

Auto-scan network dengan CIDR notation. Ping sweep, port scanning, dan auto-detection device type berdasarkan open ports.

✎️
Config Generator

Generate konfigurasi dinamis dari template Jinja2 dengan variable substitution. Push config dengan merge/replace/delete.

⚡
Task Execution

Eksekusi command bulk, configuration deployment, dan scheduled tasks. Parallel execution untuk multiple devices.

🗺
Network Topology

Visualisasi interaktif topologi jaringan dengan auto-discovery connections dan device relationship mapping.

🔧
Automation

Automation task untuk backup, monitoring, compliance check, dan interface configuration. Scheduled jobs support.

04 — Alur Data

Dari input pengguna sampai eksekusi di device

Setiap aksi di frontend melalui API call ke backend, yang kemudian menjalankan perintah di device via Netmiko.

Langkah 1 Input di Frontend

User memasukkan credentials atau memilih device dan commands di UI.

→
Langkah 2 API Request

Frontend mengirim POST/GET request ke FastAPI backend.

→
Langkah 3 Backend Processing

FastAPI memproses request, menyimpan data, dan menjalankan background task.

→
Langkah 4 Device Execution

Connection Manager menjalankan perintah via Netmiko/Napalm ke device.

→
Langkah 5 Response & Update

Hasil dikembalikan ke frontend via HTTP response atau WebSocket real-time.
